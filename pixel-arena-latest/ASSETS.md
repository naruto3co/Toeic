# Pixel heroes v2

File: `dist/assets/pixel-heroes-v2.webp`. Created with the built-in ImageGen tool, converted losslessly to WebP with transparency retained. CSS presents three cells of the atlas as the playable heroes.

Prompt:

> Use case: stylized-concept. Asset type: a production pixel-art character sprite atlas for a Vietnamese vocabulary boss battle browser game. Create exactly THREE isolated full-body playable hero sprites on a genuinely transparent background in a wide horizontal image, three equally sized square cells in a single row, with ample transparent spacing so no part crosses a cell. Left cell: sturdy silver and teal knight with broad shield and glowing short sword. Middle cell: violet robed wizard with pointed hat and cyan crystal staff. Right cell: emerald hooded ranger with bow and tiny gold healing charms. Consistent premium 32-bit JRPG pixel art, visibly crisp blocky pixels, no smooth vector outlines, restrained highlights, enchanting colorful game art. Each hero faces slightly right in a heroic combat idle pose, same ground baseline, equal visible size, centered within its own one-third cell. Transparent margin around all bodies, weapons and capes. No text, no lettering, no UI, no panels, no shadows outside each cell, no environmental scene. Designed for cropping with CSS background-position into three game characters.
